# Desk Lamp Mini Kit

Beginner DIY desk lamp. Keep power unplugged until the final check.

## Parts

| ID | Name |
|----|------|
| BASE-01 | Lamp base |
| STEM-01 | Stem tube |
| SOCK-01 | Bulb socket |
| CABLE-01 | Power cable with inline switch |
| SHADE-01 | Lamp shade |
| RING-01 | Shade ring |
| BULB-01 | LED bulb |
| SCREW-M4 | M4 set screw |

## Steps

1. **Attach stem to base** — Thread stem into base, lock with set screw.
2. **Route cable through stem** — Feed cable up through base/stem; leave switch outside.
3. **Wire the bulb socket** — Mount socket, clamp leads under L and N.
4. **Mount the shade** — Seat shade, lock with shade ring.
5. **Install bulb and safety check** — Screw in bulb, switch OFF, plug in, test.
